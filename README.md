# Pretiosus Mafia

Telegram-бот для игры в Мафию в групповых чатах.

## Установка
pip install -r requirements.txt

## Настройка
Открой config.py и вставь свой токен от @BotFather в BOT_TOKEN.

## Запуск
python main.py

## Использование
1. Добавь бота в группу
2. Дай права администратора
3. Каждый игрок должен написать боту /start в личку
4. В группе напиши /game

## Команды
/start - регистрация
/lang - выбор языка (рус/узб)
/profile - профиль игрока
/shop - магазин предметов
/game - запуск игры в группе

## Роли
Мирные: Мирный житель, Детектив, Сержант, Доктор, Везунчик, Камикадзе, Любовница, Бомж
Мафия: Мафия, Дон, Адвокат
Нейтральные: Маньяк, Самоубийца
